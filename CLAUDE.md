# Logo Fountain

The portal is being migrated from Next.js (`apps/web`) to Laravel (`apps/portal`). **Before doing anything, read `docs/laravel-migration/RESUME.md`**, then `docs/laravel-migration/handoff.md`. They hold the current state, the next step and the working rules.

- `apps/web` is frozen. Changes need a parity test and an inventory row (`docs/laravel-migration/01-feature-inventory.md`).
- Commit and push as you go. Record progress in the story file, `stories/sprint-status.yaml` and `handoff.md`.
- Keep updates concise: overviews plus `file:line` references.
